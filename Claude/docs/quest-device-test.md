## 2. 必要な広さと安全

今の値（敵は正面2m に立ち、配置位置から半径1m の外へ出ない。プレイヤーの1.2m 手前で止まり、攻撃は頭から1.5m 以内に届く）から決めた目安：

- 立ち位置から**前方3m・後方1.5m・左右各1m**（幅2m×長さ4.5m）に物も人もないこと。敵は見えるだけだが、装着者は敵に近づいて剣を振り、攻撃を避けるために下がる。
- 剣はコントローラを振る（刃 0.9m は見えるだけ）。腕を伸ばして振っても壁・家具に当たらないこと。
- 段階 A・B は**立ち止まって**行う。歩くのは段階 D だけ。
- 場所が狭い場合は、敵の距離（`FixedEnemyPlacement` の Distance）と安全範囲（`BattleController` の Enemy Leash Radius）を小さくして APK を作り直す（Claude に連絡。所要約20分）。

## 3. Mac 側の準備（1回だけ）

```bash
cd ~/dev/Ordinal-Scale            # 検証コピー
tools/quest/quest_device.sh check  # 端末・開発者モード・USB デバッグの確認
```

| check の表示 | すること |
| --- | --- |
| `OK: 端末は使える状態です` | 機種・OS の行を記録票へ写し、次へ |
| `NG: USB デバッグが未許可` | ヘッドセットを装着し「USB デバッグを許可しますか」で**許可**（このコンピュータを常に許可）→ もう一度 check |
| `NG: 端末が見えません` | 開発者モードがオフ、または充電専用ケーブル。開発者モードをオンにしてヘッドセットを再起動し、データ通信できるケーブルで挿し直す |
| `adb が見つかりません` | Unity Hub で 6000.5.10f1 に Android Build Support（SDK & NDK Tools）を追加するか、`ADB=<adb のパス>` を付けて実行 |

```bash
tools/quest/quest_device.sh install   # 既定は OrdinalScale/Builds/Android/OrdinalScale_Quest_dev.apk
```

表示された SHA-256 を記録票の「APK 識別子」に写す。`INSTALL_FAILED_…` が出たら全文を残して中断する。

## 4. 確認の順番

各段階は `run <ラベル>` で始める。**アプリを起動し直し**、`[OrdinalScale]` の行とエラーを Mac に表示しながら保存する。終わったら Mac で **Ctrl-C**。集計が表示され、次の2つが保存される。

- `Claude/reports/evidence/YYYYMMDD-HHMMSS_Q5_<ラベル>_ログ.txt`：集計と `[OrdinalScale]`・エラーの行（コミットする）
- `OrdinalScale/Builds/DeviceLogs/…_logcat_full.txt`：生ログ（`.gitignore` 済み。GitHub に入れない）

ヘッドセット内では Editor の画面左上・右上の文字（回数・HP の数字）は**出ない**。見て分かるのは次の反応だけなので、回数は Mac のログで数える。

| 見えるもの | 意味 |
| --- | --- |
| 水色の棒（刃） | コントローラを追跡中 |
| 刃が黄色 | 振りとして数えている間 |
| 刃が赤＋敵が白く光る | 命中 |
| 刃が青 | ゆっくり接触（不命中） |
| 刃が紫 | 同じ振りでの再接触（不命中） |
| 敵の頭上の赤いバー／その下の青いバー | 敵の HP／プレイヤーの HP |
| 敵の頭上の赤い球 | 攻撃の予告（約0.8秒後に攻撃。下がれば避けられる） |

### 段階 B：剣の判定の測定（Q1・Q-2、約30分）

```bash
tools/quest/quest_device.sh run sword --practice
```

`--practice` は**剣の測定モード**：敵は動かず攻撃せず、命中しても HP を減らさない（Mac に `[Q5] 剣の測定モード…` と表示される）。しきい値を測るための補助で、**受入（Q-2）の合否はここでは決めない**（段階 C で決める）。

各場面を**5回ずつ**、場面ごとに一呼吸おいて行う。記録者は場面の区切りで Mac の表示に目印（場面番号）をメモする。

| # | 場面 | 操作（コントローラ） | 期待 |
| --- | --- | --- | --- |
| B1 | 空振り | 敵の頭より上を素早く横に払う | 刃が黄色→水色。`結果=空振り` |
| B2 | ゆっくり押し当て | 刃を胸の横からゆっくり（2秒以上）胴へ入れる | 刃が青。`不命中：ゆっくり接触` |
| B3 | 有効な命中 | 胸の高さを素早く横に払って胴を通す | 刃が赤・敵が光る。`命中 振り#…`、`測定モードの命中 N 回目` |
| B4 | 触れ続け | B3 と同じく払い、胴の中で止めて1秒待ってからゆっくり抜く | 命中は1回だけ。`触れ続け（追加の命中なし）` |
| B5 | 1振りで再接触 | 止めずに右→左へ往復させて胴を2回通す | 1回目は赤、2回目は紫。`同じ振り#…で再接触` |
| B6 | 別の振り | 払う→0.3秒止める→反対へ払う | 命中が2回 |
| B7 | 自然な振り | 装着者が「斬った」と思う振り方を自由に5回 | 5回とも命中が望ましい |

Ctrl-C の後の集計のうち、次の3行をしきい値の判断に使う（現在は振りの開始 **1.5 m/s**・終了 **0.6 m/s**、いずれも仮）。

```
- 振りの最大刃先速度: …件 最小… 最大… m/s […]
- ゆっくり接触の刃先速度: …
- 命中時の刃先速度: …
```

| 結果 | 判断 |
| --- | --- |
| B2 がすべて青、B3・B7 がすべて赤 | 今の値のままでよい |
| B3・B7 で青（ゆっくり接触）になった回がある | 開始 1.5 m/s が高すぎる。B2 の速度の最大より上、B3・B7 の振りの最大速度の最小より下に下げる |
| B2 で赤（命中）になった回がある | 開始が低すぎる。B2 の速度より上に上げる |
| B4・B5・B6 が期待と違う | 終了 0.6 m/s と止める時間（0.08秒）の問題。ログをそのまま Claude へ渡す |
| `追跡の途切れ` や `位置の飛び` が多い | コントローラの追跡の問題。照明・持ち方を記録し Claude へ |

値を変える場合は `Assets/_Project/Settings/SwordTuning.asset` を変えて APK を作り直し、段階 B をもう一度行う（1回あたり約20分）。決めた値は段階 C の前に固定する。
