# システム設計の基本方針
1. **マルチデバイス対応（マルチプラットフォーム設計）**:
   - プラットフォーム固有（Meta XR SDK / NRSDK）の機能は抽象化インターフェース（`IARSpatialProvider`, `IInputController` など）で隠蔽し、ゲームロジック（エネミーのHP、攻撃判定、UIアニメーションなど）はQuestでもARグラスでも共通で動く構造にする。
2. **グラス特化型UI/UX（SAO風）**:
   - 視野角（FOV 50°〜57°）の制限を考慮した画面端のUI配置。
   - 現実の背景に埋没しない発光（Add/Screen合成）シェーダーや太いアウトラインを用いた可視性の担保。
