## 要点

- 敵1体が**配置位置から半径1mの安全範囲の内側だけ**でプレイヤーへ近づき、**予告してから攻撃**する。攻撃の瞬間に届く距離にいればプレイヤーの HP が1減る（予備動作中に下がれば避けられる）。
- **プレイヤーHP 5（仮）が0で敗北**。勝敗どちらからも「終了」「再挑戦」を選べ、再挑戦で**敵・双方のHP・剣の判定・敵の行動を初期化**する。
- Core テストは **175件すべて成功**（クラウドで実行。Q3 の追加は22件）。**Q3 の Unity 側コードは Unity Editor で未確認、Quest 実機での結果はすべて未確認**。
- 既存の Q0〜Q2 の判定・表示・iPhone 経路は変更していない（Q2 の `BattleController`・`BattleView` を Q3 用に拡張）。`GPT/`・Fab 原本・APK は変更していない。APK は再ビルドしていない。

## 技術判断（数値はすべて仮・試遊と実機で調整）

| 判断 | 内容 | 理由 |
| --- | --- | --- |
| HP 制 | プレイヤーHP 5、敵の攻撃1回で1ダメージ。敵HP 10 は Q2 のまま | Q-3「HP制・攻撃頻度・ダメージ値は技術側の提案待ち」への提案。敵の攻撃は約2.8秒ごとなので、動かない場合は開始から約15秒で敗北し、10回当てる余裕もある |
| 安全な範囲の移動 | 配置位置（プレイヤーの正面2m）から半径1m の外へ出ない。攻撃距離1.2m より内側へは自分から寄らない | プレイヤーが離れても部屋の中を追いかけず、体に重なる位置まで来ない（Q-6 の安全な小範囲） |
| 反撃 | 接近 → 予備動作0.8秒（頭上に赤い予告・Fab モデルは攻撃アニメ）→ 攻撃の瞬間に頭が1.5m 以内なら命中 → 硬直2秒 | 予告と回避の余地を作り、理不尽な被弾にしない |
| 規則を Core に置く | `EnemyBrain` は水平面の純粋な状態機械（処理落ちでも1回0.1秒までしか進めない）。勝敗は `BattleSession` | Unity なしで時間の進み方・安全範囲・状態の混線をテストできる |
| 決着後の攻撃無効 | 剣の判定と敵の行動の両方を止め、`BattleSession` も決着後の命中・被弾を無視（二重） | 勝利と同じフレームに来た敵の攻撃で敗北に変わらない |
| 敗北時の敵 | その場で止めて表示したまま（勝利時は Q2 どおり消す） | どこから攻撃されたか分かるようにする |

## テスト（クラウド。長いログは省略）

- Core **175件成功**（153＋22）。NUnit 互換の仮ランナー（フィクスチャを使い回し `[SetUp]` を呼ぶ）で実行。
- 主な確認：開始待ち／1.2m で停止／高速でも攻撃距離の内側へ踏み込まない／プレイヤーが離れても半径1m の外へ出ない／予備動作後に命中／下がれば回避／約2.8秒ごとの繰り返し／処理落ちの上限／プレイヤーHP 4回では敗北せず5回目で敗北／敗北後は剣も被弾も無効／勝利後の被弾は無視／敗北・勝利どちらからも2択／再挑戦で双方の HP と回数を初期化／勝利→敗北→勝利のラウンドで状態が混ざらない／敵と戦闘をつないで動かないプレイヤーが約15秒で敗北。
- 規則の破壊6通り（再挑戦でプレイヤーHPを戻さない、決着後も被弾、安全範囲なし、攻撃距離の内側まで寄る、避けても当たる、処理落ちの上限なし）はすべて対応するテストが失敗。最初は「攻撃距離の内側まで寄る」を既定の速さでは検出できず、高速の敵のテストを足した。
- Unity 側：Unity API の最小スタブで型検査（Input System＋`UNITY_EDITOR`、旧 Input Manager）が成功。**Unity 本体でのコンパイル・EditMode・設定検証は開発者の環境で必要**。
