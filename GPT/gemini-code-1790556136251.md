# プロジェクト概要
- **目的**: 『ソードアート・オンライン オーディナル・スケール』に登場するARデバイス「オーグマー」およびゲーム「オーディナル・スケール」の体験を模したARバトルゲームのプロトタイプ開発。
- **ターゲットデバイス**: XREAL等のメガネ型ARグラス（最終成果物）
- **補助検証デバイス**: Meta Quest 3 / 3S（学校の実機を活用し、高精度な空間認識・ハンドトラッキングの先行検証用）

# 開発ロードマップ案（概要）
- **STEP 1**: 学校のQuestを用いた空間認識＆ゲーム基本ロジック（エネミー生成・攻撃判定・HP管理）の作成（1〜2週間）
- **STEP 2**: メガネ型ARグラス（XREAL等）の選定・購入および接続・NRSDKセットアップ（1週間）
- **STEP 3**: Questで検証したロジックのARグラスへの移植と「グラス特化UI（FOV考慮・透過視認性）」の最適化（2〜3週間）
- **STEP 4**: 空間固定（6DoF）の精度向上・マルチプレイ同期（Photon等）の検証（継続）
