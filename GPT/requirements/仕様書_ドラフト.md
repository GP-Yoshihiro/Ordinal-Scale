# オーディナル・スケール型ARバトル試作 仕様書

状態：**ドラフト／要件インタビュー中**。ユーザーが体験・範囲・期限を確認するまで確定版としない。技術方式はClaudeが実現性を確認する。

## 目的と対象

『ソードアート・オンライン オーディナル・スケール』に着想を得たARバトル体験を試作する。誰に、どの場で、いつ見せるか、および固有の名称・素材をどこまで使うかは未確定。

開発は個人。最終デバイス候補はXREAL等のメガネ型ARグラスで、Quest 3／3Sを先行検証に使う。2026年9月28日週はQuest実機を利用できないため、Editor内の戦闘ループを先に確認する。

## Editor試作の受入条件案

| ID | 観察できる結果 | 確定状態 |
| --- | --- | --- |
| E1 | 所定のシーンを再生するたび、敵1体が表示される | 案 |
| E2 | 同じ入力手順で命中と外れを再現でき、外れでは敵HPが減らない | 案 |
| E3 | 命中時に分かる反応があり、画面または検証ログでHP減少を確認でき、設定回数の命中で撃破状態になる | 案。初期HP・ダメージ・回数・表示方法は未定 |
| E4 | 再開始の操作で敵とHPが初期状態に戻り、同じ流れを繰り返せる | 案。撃破後の状態と再開始操作は未定 |
| E5 | 開発者が再現手順・結果・未確認事項を記録する。Questでの動作をEditorの結果から推定しない | 案 |
